# jarvis-landing

Landing page for **JARVIS** — the voice assistant that runs your computer.

Dark HUD design system per `jarvisv1-floot-app` spec: Deep Space Navy
`#080B16`, Electric Cyan `#4FD8FF`, pill CTAs (28px), SF Pro Text +
IBM Plex Mono, flat cards with slate borders, quoted-prompt capability
callouts.

Sections: hero + animated HUD (telemetry, windows, activity log),
6 capabilities, setup in 3 steps, Personal/Pro pricing, FAQ, final CTA.

Zero dependencies.

```bash
npm start        # → http://localhost:3006
```
