FAQ

Asked before launch. Answered anyway.

Does JARVIS send my screen or files to a server?

No. Wake word, commands and screen reads are processed on your machine. The only network calls are the live-search queries you explicitly ask for — and Pro's encrypted sync between machines you own.

What stops it from doing something destructive?

Every irreversible action — deleting, sending, purchasing, killing processes — requires a spoken or clicked confirmation. You can also pin a per-app allowlist so some software is simply out of reach.

Which platforms are supported?

macOS 13+, Windows 11, and the major Linux desktops (GNOME, KDE). The core voice loop ships everywhere; deep window management follows each OS's native APIs.

Can it work fully offline?

Yes — everything except live web search runs with the network cable pulled. That's the point of local-first: your assistant works in airplane mode.

How is Pro billed?

$12 per month, or $10 per month billed annually — save 17%. Card or bank transfer, cancel anytime from the app. Personal stays free forever — it is not a trial.
